# 建筑节能监测平台前端
> 青岛艾德森物联科技有限公司 | 实习前端项目 Vue3 + Vite

## ✨ 项目介绍
建筑节能项目配套Web监控页面，面向楼宇能耗、供冷监测场景开发数据可视化大屏。实现能耗指标卡片、能耗趋势图表、设备状态监控表格，用于展示建筑用电、用水、碳排放等监测数据。

## 📄 负责内容
前端页面开发、组件封装、ECharts图表渲染、页面布局适配，对接模拟接口完成数据展示；部署时处理GitHub Pages静态资源路径问题。

## 🛠 技术栈
- Vue3 `<script setup>`
- Vite
- ECharts 数据可视化
- Axios
